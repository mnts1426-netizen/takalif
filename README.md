# متابعة تكاليف الطلاب

نظام بسيط لمتابعة تسليم تكاليف طلاب النادي: من سلّم، وكم بقي عليه، وهل أكمل.
فيه قسمان منفصلان: **الأشبال** و**الفتيان**، ولكل قسم طلابه وتكاليفه الخاصة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع كاملًا (الواجهة + التنسيق + البرمجة) — هذا الملف الوحيد الذي يُنشر |
| `README.md` | هذا الدليل |

لا توجد مكتبات إضافية غير Firebase (تُحمَّل تلقائيًا من موقع Google).

> ⚠️ **الدخول مفتوح بلا كلمة مرور** (بناءً على طلبك): أي شخص يملك رابط الموقع يستطيع رؤية أسماء الطلاب والتعديل عليها.
> شارك الرابط مع المشرفين فقط. وإن احتجت حماية لاحقًا، يمكن إضافة كلمة مرور للدخول دون تغيير البيانات.

## 1) ربط Firebase خطوة بخطوة

> ⚠️ **أنشئ مشروع Firebase جديدًا خاصًا بهذا النظام.** لا تستخدم مشروع الحلقات أو مشروع المنصة؛
> لأن قواعد Firestore واحدة لكل مشروع، ولصق قواعد هذا النظام هناك سيغيّر صلاحيات التطبيقات الأخرى.

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) ← **Add project** ← اكتب اسمًا (مثل `takaleef`) ← يمكنك إيقاف Google Analytics ← **Create**.
2. من صفحة المشروع اضغط أيقونة الويب **`</>`** ← اكتب اسمًا للتطبيق ← **Register app** (لا تفعّل Hosting الآن).
   سيظهر لك كود فيه `firebaseConfig`. انسخ القيم الست.
3. افتح `index.html` بأي محرر نصوص، وابحث عن هذا الجزء في أعلى قسم البرمجة:
   ```js
   const firebaseConfig = {
     apiKey: "ضع_هنا",
     authDomain: "ضع_هنا",
     ...
   ```
   ضع قيمك مكان كل `ضع_هنا` (مع إبقاء علامات التنصيص) ثم احفظ الملف.
4. **Build ← Firestore Database ← Create database** ← اختر الموقع (مثل `eur3` أو أقرب منطقة) ← اختر **Start in production mode** ← **Create**.
5. **القواعد:** Firestore ← تبويب **Rules** ← احذف الموجود والصق القواعد من القسم التالي ← **Publish**.

لا حاجة لتفعيل Authentication ولا لإنشاء حسابات.

> لو اخترت **Test mode** بدل القواعد التالية: سيعمل الموقع، لكن Google توقف الوصول تلقائيًا بعد 30 يومًا فيتوقف الموقع.
> القواعد التالية لا تنتهي، وتقصر الوصول على بيانات القسمين فقط.

## 2) قواعد Firestore

(النص نفسه موجود أيضًا داخل الموقع في شاشة الإعداد.)

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // الدخول مفتوح بلا كلمة مرور، ومقصور على قسمي الأشبال والفتيان فقط
    function okGroup(g) {
      return g in ['ashbal', 'fityan'];
    }
    function validText(f) {
      return request.resource.data[f] is string &&
        request.resource.data[f].size() > 0 &&
        request.resource.data[f].size() <= 120;
    }
    match /groups/{g}/students/{id} {
      allow read, delete: if okGroup(g);
      allow create, update: if okGroup(g) && validText('name');
    }
    match /groups/{g}/assignments/{id} {
      allow read, delete: if okGroup(g);
      allow create, update: if okGroup(g) && validText('title');
    }
    match /groups/{g}/submissions/{studentId} {
      allow read, write: if okGroup(g);
    }
    // أي مسار آخر مرفوض تلقائيًا
  }
}
```

ما تفعله: تسمح بالقراءة والكتابة على بيانات القسمين فقط، وترفض أي مسار آخر، وترفض الأسماء الفارغة أو الأطول من 120 حرفًا.

## 3) النشر

### الطريقة أ: GitHub Pages (مثل المشاريع السابقة)
1. في GitHub ← **New repository** ← اسم مثل `takaleef` ← Public ← **Create repository**.
2. **Add file ← Upload files** ← ارفع `index.html` (بعد وضع إعدادات Firebase فيه) ← **Commit changes**.
3. **Settings ← Pages** ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-حسابك.github.io/takaleef/`.

لتحديث الموقع لاحقًا: ارفع `index.html` الجديد بنفس الطريقة (يستبدل القديم).

### الطريقة ب: Firebase Hosting
1. ثبّت Node.js، ثم من موجه الأوامر داخل مجلد المشروع:
   ```bash
   npx firebase-tools login
   ```
   ```bash
   npx firebase-tools init hosting
   ```
   اختر المشروع، واكتب `.` كمجلد public، وأجب **No** على سؤال single-page app، و**No** على استبدال `index.html`.
2. ```bash
   npx firebase-tools deploy --only hosting
   ```
   الرابط يكون: `https://اسم-المشروع.web.app`.

## 4) طريقة الاستخدام

- **الدخول:** افتح الرابط ← اضغط **دخول الأشبال** أو **دخول الفتيان**.
  الجهاز يتذكر آخر قسم ويفتحه مباشرة في المرة القادمة. للانتقال للقسم الآخر: زر **تغيير القسم** أعلى الصفحة.
- **تبويب «الطلاب والمتابعة» (الصفحة الرئيسية):**
  - أعلى الصفحة: عدد الطلاب، عدد التكاليف، من أكملوا الكل، نسبة التسليم العامة (للقسم الحالي).
  - **إضافة طالب:** اكتب الاسم ← «إضافة طالب». لإضافة قائمة كاملة: «إضافة عدة طلاب دفعة واحدة» ← كل اسم في سطر.
  - كل طالب يظهر ببطاقة فيها: المسلّمة من الإجمالي، المتبقية، النسبة، والحالة (مكتمل / غير مكتمل).
  - اضغط على البطاقة ← تظهر التكاليف بمربعات اختيار. ضع علامة = سلّم، أزلها = لم يسلّم. يُحفظ فورًا.
  - البحث بالاسم (لا يتأثر بالهمزات أو التاء المربوطة)، وزرّا «الكل» و«غير المكتملين».
  - حذف الطالب: من داخل بطاقته (بعد فتحها) ← «حذف الطالب» ← تأكيد.
- **تبويب «إدارة التكاليف»:** إضافة تكليف (إذا تركت الاسم فارغًا يُسمّى تلقائيًا «التكليف رقم N»)، تعديل الاسم، أو الحذف بعد التأكيد.
  التكليف الجديد يظهر فورًا لكل طلاب القسم على أنه غير مسلّم، وحذفه يزيل تسليمه من كل طلاب القسم.
- **عند انقطاع الإنترنت:** يظهر شريط أحمر أعلى الصفحة، ولا يُرسل أي تعديل (تظهر رسالة «لم يُحفظ التغيير»).
  رسالة «تم الحفظ» لا تظهر إلا بعد تأكيد الخادم.

## 5) بنية قاعدة البيانات

كل قسم في مسار مستقل: `groups/ashbal/...` للأشبال، و`groups/fityan/...` للفتيان.

| المجموعة (داخل كل قسم) | معرّف الوثيقة | الحقول |
|---|---|---|
| `students` | تلقائي ثابت | `name`, `createdAt` |
| `assignments` | تلقائي ثابت | `title`, `order`, `createdAt` |
| `submissions` | **= معرّف الطالب** | `studentId`, `done: { <معرّف التكليف>: true }`, `updatedAt` |

- الربط بالمعرّفات فقط، فتغيير اسم طالب أو تكليف لا يكسر أي سجل.
- سجل تسليم واحد لكل طالب، والمفتاح داخله معرّف التكليف ← **لا يمكن أن يتكرر** تسجيل نفس التكليف، وتغيير الحالة يعدّل نفس السجل.
- لماذا وثيقة لكل طالب وليس لكل (طالب × تكليف)؟ لتقليل القراءات: 300 طالب × 40 تكليف = 12,000 وثيقة بالطريقة الأخرى، بينما هنا ≈ 300 فقط عند فتح القسم (الحد المجاني اليومي 50,000 قراءة).
- الحساب يعدّ فقط التكاليف الموجودة حاليًا، فلا تتأثر الأرقام بأي بقايا لتكليف محذوف.
- النسبة تُقرَّب للأسفل، فلا تظهر 100% إلا عند الاكتمال الفعلي. وإذا لم توجد تكاليف تظهر «—» بدل أرقام خاطئة.

### بعد وضع إعداداتك — تحقق سريع (5 دقائق)
1. ادخل الأشبال ← أضف طالبًا وتكليفًا ← ضع علامة.
2. افتح الموقع من جوال آخر ← ادخل الأشبال ← يجب أن ترى نفس البيانات. ثم ادخل الفتيان ← يجب أن يكون فارغًا.
3. في Firestore تأكد من ظهور `groups` ← `ashbal` ← `students` و`assignments` و`submissions`.
